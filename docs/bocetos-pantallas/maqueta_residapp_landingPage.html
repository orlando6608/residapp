SEGURIDAD CORPORATIVA B2B

Preguntas frecuentes sobre la protección de datos

¿Dónde se almacenan físicamente los datos de los residentes y las familias?

Toda nuestra infraestructura, servicios y la base de datos única multi-tenant están alojados de forma nativa en Microsoft Azure, garantizando el almacenamiento de la información estrictamente en centros de datos ubicados dentro de la Unión Europea. Esto asegura el cumplimiento total de la RGPD y los más altos estándares de soberanía de datos sanitarios.

Al ser una base de datos unificada, ¿existe riesgo de filtración o cruce de datos entre residencias?

No. Aunque compartimos una arquitectura de base de datos única por eficiencia de costes, el sistema cuenta con un filtrado lógico estricto e infranqueable basado en el ID de centro asignado a cada cuenta profesional. Un usuario de una residencia jamás puede realizar peticiones a los datos de otra, y cada acción de acceso y consulta queda totalmente registrada en nuestra auditoría inmutable de trazabilidad clínica.

¿Qué datos clínicos o médicos se muestran en el Portal Familiar?

Por seguridad y confidencialidad, las familias nunca tienen acceso directo a las gráficas de constantes médicas, valoraciones detalladas, tratamientos farmacéuticos ni nombres de profesionales sanitarios. El sistema únicamente les muestra un canal de novedades comprensibles y resúmenes de bienestar autorizados y preparados explícitamente por el equipo asistencial del centro al cerrar un evento ordinario o prioritario.
