# Pendientes de CJ

Documentos que CJ tiene que completar: valores clínicos y decisiones de producto que ingeniería no puede
inventar. Cuando CJ los completa, ingeniería revisa las respuestas y las incorpora a la aplicación.

## Cómo completarlos

1. Abrir el documento en GitHub y pulsar el lápiz para editarlo.
2. Buscar «por definir» (Ctrl+F) y sustituirlo por el valor o la respuesta.
3. Pulsar «Commit changes».

Los `.html` se ven en GitHub como código. Para leerlos con formato, descargarlos («Download raw file») y
abrirlos en el navegador.
